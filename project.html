Project 01 · Control Systems

Intelligent Electric Power Steering System

01 The Challenge

Develop a steering-assistance system that adapts motor assistance to driving conditions and steering input while remaining practical to implement in a physical prototype.

02 My Approach

Designed a fuzzy-logic-based adaptive controller using vehicle velocity, steering effort, and yaw rate as inputs to determine motor torque. A PID controller was also considered for evaluation.

03 System Design

The system combined the steering mechanism, motor, torque measurement, and control unit. The controller was evaluated in simulation before integration with the physical cart prototype.
