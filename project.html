PROJECT 01

Intelligent Electric Power Steering System

Designed and developed a functional cart prototype featuring an intelligent electric power steering system that adapts steering assistance to driving conditions.

Control Systems MATLAB / Simulink SolidWorks

Project Overview

Developed a physical cart prototype to investigate an intelligent electric power steering system. The project combined mechanical design, control development, and prototype integration.

Technical Work

  • Designed mechanical components and assemblies using SolidWorks.
  • Developed a fuzzy-logic-based adaptive controller using vehicle velocity, steering effort, and yaw rate as inputs.
  • Evaluated steering assistance in MATLAB/Simulink and integrated the system into a physical prototype.

Tools

SolidWorks, MATLAB, Simulink, control systems, physical prototyping.
